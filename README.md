# Game of Life

## Elements

This game of life simulation borrows elements from the video game _Genshin Impact_. These elements are:

- **Anemo (wind)**
- **Geo (rock)**:
- **Electro (thunder)**
- **Dendro (grass)**
- **Hydro (water)**
- **Pyro (fire)**
- **Cryo (ice)**

The additional states are:
- **Empty**: the null object to replace null and makes code safer. takes over if a tile dies without replacement.
- **Ash**: produced by **Pyro** or withered **Dendro**. The second weakest Tile and can be taken over like Empty.
- **Core**: generated by **Dendro** in **hyperbloom** reaction. The class extends Dendro so other element can react with it, but Dendro-side reaction won't happen.

### Categories

- **Strong Types (Pyro, Hydro, Electro, Cryo)**: Can cause Geo's crystallize reaction and Anemo's swirl reaction.
- **Complex Types (Electro, Anemo, Core)**: can contain simpler tiles (through aggregation). Contained tiles are treated equally and can react as usual with other tiles.

### States and Display

Some tiles have special states, displayed as small squares in the center of a tile on the grid.

- **Complex tiles (Anemo, Electro, Core)**: Display the color of the tile it contains by default.
- **Pollinated (Anemo)**: Plant on one empty tile when pollinated. No display.
- **Shield (Geo)**: Shielded Geo can't become brittle and can't die in erosion or overloaded. Display Geo color.
- **Brittle (Geo)**: Brittle Geo are 100% destroyed when encountering wind. Display Cryo color. 
- **Dendro Core (Dendro)**: Core automatically explodes in 6 ticks and plant Dendro on all nearby Empty tile. Display Dendro color.
- **Frost (Dendro)**: Can't grow, overwrites quickened. Display Cryo color if no Core.
- **Quickened (Dendro)**: Grow faster. Display Electro color if no Core.
- **Lake (Hydro)**: Becomes Lake and persists if connected to at least one other Hydro, otherwise dies in 15 ticks. Display Hydro color.

### Priorities

Tiles have priorities. Lower priorities can act first and are less likely to be overwritten.

## Main Rules

### Tiles

1. **Growth**: Dendro spreads to an empty neighbor 5% each tick, doubled if Hydro is within 2 tiles.
2. **Wither**: Dendro with no Hydro or Cryo within 2 tiles die in 30 ticks.
3. **Rain**: a random tile becomes Hydro each tick.
4. **Burnout**: Pyro lasts 3 turns and becomes Ash.
5. **Thaw**: Cryo becomes Hydro in 20 ticks.
6. **Mountains**: Each connected component of Geo 5% grow one Geo at a random adjacent tile. The mountains grow quicker when small.
7. **Storms**: Random number of Electro appears at random place 10% each tick. Go to random adjacent tile each tick, and die in 15 ticks.
8. **Wind**: Anemo winds appear at a random first tile in the current seasonal wind direction.
9. **Ash**: generated by died Pyro and withered Dendro. Dendro grows 2x faster on it.

### Reactions

10. **Burning (Pyro x Dendro)**: Fire spreads to adjacent Dendro 20%.
11. **Vaporize (Pyro x Hydro)**: Hydro kills Pyro 50%, and when doing so 30% die.
12. **Melt (Pyro x Cryo):** Cryo becomes Hydro and Pyro dies.
13. **Frozen (Hydro x Cryo)**: Hydro with >=2 Cryo freezes 5%.
14. **Overloaded (Pyro x Electro)**: when Electro above Pyro, clears 5x5 areas and spawn a Pyro at a random place 3 tiles away.
15. **Electro-Charged (Hydro x Electro)**: when Electro above Hydro, the Hydro becomes charged and spread to 30 nearby Hydro at maximum in the lake.
16. **Superconduct (Cryo x Electro)**: when Electro above Cryo, both die, make adjacent Geo brittle.
17. **Quicken (Dendro x Electro)**: Dendro becomes quickened and grows 3x faster for 5 ticks.
18. **Bloom (Dendro x Hydro)**: Dendro next to Hydro 3% grow a Dendro Core.
19. **Burgeon (Core x Pyro)**: Dendro Core turns all Dendro within 2 tiles into Pyro.
20. **Hyperbloom (Core x Electro)**: when Electro above a Dendro with core, it becomes a Core tile and hunts down the nearest Pyro and kills all Pyro.
21. **Swirl (Anemo x Strong types)**: when Anemo above a strong typed tile, it swaps the tile with a random adjacent simple tile, possibly duplicating it.
22. **Crystallize (Geo x Strong types)**: if Geo adjacent to strong types, it 10% gets a shield for 20 turns and absorb the strong tile.
23. **Frost (Dendro x Cryo)**: Dendro next to Cryo or in the winter stops growing.
24. **Pollination (Dendro x Anemo)**: when Anemo above Dendro, Anemo becomes pollinated and plant a new Dendro at a empty tile that it passes.
25. **Erosion (Geo x Anemo)**: when Anemo above Geo, 2% kills Geo.

## Seasons

Each season 100 ticks. Change the seasonal wind to random one of 8 directions when season changes.

- **Spring**: Dendro grow x1.5 faster. Bloom chance x2.
- **Summer**: 1% fire on random Dendro. Water dry out x2 quicker.
- **Fall**: Storms chance x3. Wind chance x2.
- **Winter**: Cryo won't thaw. Frozen chance x8. Dendro don't grow.
