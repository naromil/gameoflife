# Game of Life

## Architecture

- `MainController` and `Sim` are the main functions that is responsible for the UI, JavaFX logic, rendering and the `Grid` instance.
- `SeasonType` is an enum for the four seasons. `Color` and `Point` are the record.
- All tile classes extend the abstract class `Tile`. `Core` extends `Dendro`.
- `Grid` interacts with `Tile` class only and access the list of actual tile classes using `TileFactory`. `Grid` itself stores `Season`.
- `Tile` has an `containedTile` field that is mostly used in complex tiles.
- The `Grid` wrapper method `replace(Grid, position, Tile, Tile)` safely replaces a Tile with another Tile based on UUID matching to ensure priority. It also smartly replaces `containedTile` to achieve abstraction.
- `Grids` is the utility class used to explore `Grid`, such as getting neighbors and tracking distances.

## Get Started

- Run `./gradlew run` in the project root to compile and run.
- The document containing all the rules is in `README.md` in the project root.
- The source files (.java files) are in `src/main/java/com/naromil/gol`.
- The JavaFX fxml layout file is in `src/main/resources/com/naromil/gol`.
- The editing history (commits) of the code can be viewed on Github directly or by cloning the repo.

## Elements

This game of life simulation borrows elements from the video game _Genshin Impact_. These elements are:

- **Anemo (wind)**
- **Geo (rock)**
- **Electro (thunder)**
- **Dendro (grass)**
- **Hydro (water)**
- **Pyro (fire)**
- **Cryo (ice)**

The additional states are:
- **Empty**: the null object to replace null and makes code safer. takes over if a tile dies without replacement.
- **Ash**: produced by **Pyro** or withered **Dendro**. The second weakest Tile and can be taken over like Empty.
- **Core**: generated by **Dendro** in **hyperbloom** reaction. The class extends Dendro so other element can react with it, but Dendro-side reaction won't happen.

### Categories

- **Strong Types (Pyro, Hydro, Electro, Cryo)**: Can cause Geo's crystallize reaction and Anemo's swirl reaction.
- **Complex Types (Electro, Anemo, Core)**: can contain simpler tiles (through aggregation). Contained tiles are treated equally and can react as usual with other tiles.

### States and Display

Some tiles have special states, displayed as small squares in the center of a tile on the grid.

- **Complex tiles (Anemo, Electro, Core)**: Display the color of the tile it contains by default.
- **Pollinated (Anemo)**: Plant on one empty tile when pollinated. No display.
- **Shield (Geo)**: Shielded Geo can't become brittle and can't die in erosion or overloaded. Display Geo color.
- **Brittle (Geo)**: Brittle Geo are 100% destroyed when encountering wind. Display Cryo color. 
- **Dendro Core (Dendro)**: Core automatically explodes in 6 ticks and plant Dendro on all nearby Empty tile. Display Dendro color.
- **Frost (Dendro)**: Can't grow, overwrites quickened. Display Cryo color if no Core.
- **Quickened (Dendro)**: Grow faster. Display Electro color if no Core.
- **Lake (Hydro)**: Becomes Lake and persists if connected to at least one other Hydro, otherwise dies in 15 ticks. Display Hydro color.

### Priorities

Tiles have priorities. Lower priorities can act first and are less likely to be overwritten.

## Main Rules

The probabilities are generally checked once per round.
Global rules such as wind, storms and rain are triggered in proportion to the grid size.

### Tiles

1. **Growth**: Dendro spreads to an empty neighbor 5% each tick, doubled if Hydro is within 2 tiles.
2. **Wither**: Dendro with no Hydro or Cryo within 2 tiles die in 30 ticks.
3. **Rain**: a random tile becomes Hydro each tick. Hydro affinity: move up to 2 tiles closer to the nearest Hydro.
4. **Burnout**: Pyro lasts 3 turns and becomes Ash.
5. **Thaw**: Cryo becomes Hydro in 20 ticks.
6. **Mountains**: Each connected component of Geo 0.5% grow one Geo at a random adjacent tile. The mountains grow quicker when small.
7. **STORMS**: Random number of Electro appears at random place 5% each tick. Go to random adjacent tile each tick, and die in 15 ticks.
8. **WIND**: Anemo winds appear at a random first tile in the current seasonal wind direction.
9. **Ash**: generated by died Pyro and withered Dendro. Dendro grows 2x faster on it.
10. **Wild Fire**: 10% fire every tick on random Dendro tile.

### Reactions

11. **Burning (Pyro x Dendro)**: Fire spreads to adjacent Dendro 10%.
12. **Vaporize (Pyro x Hydro)**: Hydro kills Pyro 50%, and when doing so 50% die.
13. **Melt (Pyro x Cryo):** Cryo becomes Hydro and Pyro dies.
14. **Frozen (Hydro x Cryo)**: Hydro with >=2 Cryo freezes 5%.
15. **OVERLOADED (Pyro x Electro)**: when Electro above Pyro, clears 5x5 areas and spawn a Pyro at a random place 3 tiles away.
16. **Electro-Charged (Hydro x Electro)**: when Electro above Hydro, the Hydro becomes charged and spread to 5 nearby Hydro at maximum in the lake.
17. **SUPERCONDUCT (Cryo x Electro)**: when Electro adjacent or above Cryo, both die, spread to 5 nearby Cryo and make adjacent Geo brittle.
18. **Quicken (Dendro x Electro)**: Dendro becomes quickened and grows 3x faster for 5 ticks.
19. **Bloom (Dendro x Hydro)**: Dendro next to Hydro 3% grow a Dendro Core.
20. **Burgeon (Core x Pyro)**: Dendro Core turns all Dendro within 2 tiles into Pyro.
21. **HYPERBLOOM (Core x Electro)**: when Electro above a Dendro with core, it becomes a Core tile and hunts down the nearest Pyro and kills all Pyro.
22. **SWIRL (Anemo x Strong types)**: when Anemo above a strong typed tile, it swaps the tile with a random adjacent simple tile, possibly duplicating it.
23. **Crystallize (Geo x Strong types)**: if Geo adjacent to strong types, it 10% gets a shield for 20 turns and 10% absorbs the strong tile.
24. **Frost (Dendro x Cryo)**: Dendro next to Cryo stops growing.
25. **Pollination (Dendro x Anemo)**: when Anemo above Dendro, Anemo becomes pollinated and plant a new Dendro at a empty tile that it passes.
26. **Erosion (Geo x Anemo)**: when Anemo above Geo, 0.2% kills Geo.
27. **Plateau (Geo x Hydro)**: when Hydro adjacent to Geo, 1% turn into Cryo.

### The Complex Rules

- **7 STORMS**: storms generated in chunks and move together based on ID matching.
- **8 WIND**: wind generated at the edge, which depends on the random seasonal wind direction.
- **15 OVERLOADED**: go through random tile at distance 3 and place a Pyro.
- **17 SUPERCONDUCT**: use bfs to explore nearby Cryo and inflict special state on Geo.
- **21 HYPERBLOOM**: a specialized Dendro child class, Core, chase near Pyro at 3x speed and clear all Pyro on the old board.
- **22 SWIRL**: swap the simple tile within Anemo abstractly with adjacent with a chance to construct new one using `Class<? extends Tile>`.

## Seasons

Each season 100 ticks. Change the seasonal wind to random one of 8 directions when season changes. Changes the color of Dendro each season.

- **Spring**: Dendro grow x1.5 faster. Bloom chance x2.
- **Summer**: doubled chance wild fire on random Dendro. Water dry out x2 quicker.
- **Fall**: Storms chance x3. Wind chance x2.
- **Winter**: Cryo won't thaw. Frozen chance x8. Dendro don't grow.
